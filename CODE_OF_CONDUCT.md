# Code of Conduct

We want IntenseRP Next v2 to be a friendly place to hang out, report bugs, and ship code.
Please be kind, be patient, and assume good intent.

## The basics

- Be respectful. No insults, harassment, hate speech, or "jokes" at someone else's expense.
- Keep feedback constructive. Critique ideas/code, not people.
- Respect privacy. Don't post other people's personal info or private messages.
- Keep it safe and legal. Don't share malware, doxxing info, or anything that puts others at risk.

## Where this applies

This applies to our GitHub spaces (issues, PRs, discussions, etc.) and any community spaces run for the project.

## Reporting a problem

If something feels off, you're allowed to speak up.

- Normal project problems: open an issue at https://github.com/Lemomation/irn/issues
- Code of Conduct concerns (or anything sensitive/private): open a confidential issue or contact the repo maintainers via GitHub.

When reporting, include what happened, where it happened (links help), and what kind of outcome you'd like.

## Enforcement

Maintainers may remove content, lock threads, or block accounts to keep the community safe.
We'll try to be fair, listen first, and explain decisions when we can.

## Thanks

This is a lightweight Code of Conduct, inspired by the Contributor Covenant.
