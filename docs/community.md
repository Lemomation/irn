# :material-account-group: Get Involved

The project has grown quite a bit lately, which is honestly really nice to see!
There are now a few better places to connect depending on what you need, so you
don't have to guess where to go if you want to report something, ask for help,
or just keep up with what's happening.

If you have a bug report or a feature idea, GitHub is still the best home for
that because it keeps everything searchable and trackable. If you want quicker
back-and-forth, shared troubleshooting, or a place to talk to other people
using the project, the Discord community is a much better fit. And if you need
the full list of ways to reach out, including more direct/private options, the
contact page has all of that in one place.

<div class="grid cards" markdown>

-   :material-chat: **Discord Community**

    Best for: support, quick questions, shared troubleshooting, and casual
    discussion.

    [:arrow_right: Join Discord](https://discord.gg/4Gvjk2RdsK)

-   :material-github: **GitHub Repository**

    Best for: feature requests, bug reports, PRs, and following development.

    [:arrow_right: Open the repository](https://github.com/Lemomation/irn)

-   :material-email: **Full Contact Page**

    Best for: finding every contact option in one place, including more direct
    or private routes.

    [:arrow_right: View contact options](hands/contact.md)

</div>
